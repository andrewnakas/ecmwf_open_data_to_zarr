📊 Access the Data

Use Python and xarray to access the full dataset:

import xarray as xr

# Open the latest forecast
ds = xr.open_zarr(
    "https://andrewnakas.github.io/ecmwf_open_data_to_zarr/data/ecmwf/ifs/forecast-15-day/latest.zarr",
    decode_timedelta=True,
    chunks=None
)

# Select New York City
nyc = ds.sel(latitude=40.7, longitude=286.0, method="nearest")

# Plot 15-day temperature forecast
import matplotlib.pyplot as plt
(nyc["temperature_2m"] - 273.15).plot(x="lead_time")
plt.ylabel("Temperature (°C)")
plt.show()

ℹ️ Dataset Information

  • Model: ECMWF IFS High-Resolution
  • Resolution: 0.25° (~25 km)
  • Update Schedule: Every 6 hours (00, 06, 12, 18 UTC)
  • Forecast Horizon: 15 days (360 hours)
  • Variables: Temperature, Wind, Precipitation, Pressure, Cloud Cover, Humidity
  • Format: Zarr v3 with Blosc compression
  • Coverage: Global (90°N to 90°S, 0° to 360°E)
