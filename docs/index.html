Cloud-optimized weather forecast data, updated every 6 hours

Live Dataset Auto-Updated

📊 Quick Start

Access the latest ECMWF IFS forecast using Python and xarray:

import xarray as xr

# Open the latest forecast (replace YOUR_USERNAME)
ds = xr.open_zarr(
    "https://YOUR_USERNAME.github.io/ecmwf_open_data_to_zarr/data/ecmwf/ifs/forecast-15-day/latest.zarr",
    decode_timedelta=True,
    chunks=None
)

# Select a location (e.g., New York City)
nyc = ds.sel(latitude=40.7, longitude=-74.0, method="nearest")

# Plot 15-day temperature forecast
import matplotlib.pyplot as plt
(nyc["temperature_2m"] - 273.15).plot(x="lead_time")
plt.ylabel("Temperature (°C)")
plt.title("NYC 15-Day Temperature Forecast")
plt.show()

⚙️ Dataset Specifications

Model

ECMWF IFS HRES

Resolution

0.25° (~25 km)

Update Frequency

Every 6 hours

Forecast Horizon

15 days (360h)

Coverage

Global

Format

Zarr v3 + Blosc

📈 Available Variables

  • Temperature: 2-meter air temperature
  • Wind: U and V components at 10 meters
  • Precipitation: Total precipitation (accumulated)
  • Pressure: Surface pressure and mean sea level pressure
  • Cloud Cover: Total cloud cover fraction
  • Humidity: 2-meter relative humidity

🚀 Features

Automated Pipeline

  • GitHub Actions pulls data every 6 hours (00, 06, 12, 18 UTC + 1h delay)
  • Automatic conversion from GRIB2 to Zarr
  • Data validation and quality checks
  • Deployed to GitHub Pages for public access

Inspired by dynamical.org

  • Three-class architecture: TemplateConfig → RegionJob → Dataset
  • Cloud-optimized chunking for efficient access
  • Blosc compression for reduced storage
  • CF-compliant metadata
